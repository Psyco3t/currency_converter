# So, what is it?
This android app serves as an alternative to either looking up currency conversion or having to be completely reliant on data despite having it or not.
## Okay why though?
I actually made this for myself and for the people who are in a similar situation like myself. Where its not always guaranteed that you have access to mobile data or a free open WIFI connection
especially abroad. If for any reason you need to do a quick price check or conversion in a foreign currency this app lets you do it without being completely reliant on internet access.
## How?
Basically it uses a free API to get all the conversion rates then store them as local storage on your device, so actually it does need internet connection but only for the initial install.
The app attempts to refresh the stored rates each time it launches and you can also manually refresh it, once the rates are stored you are good to go and can use it wherever you like, though refreshing it once in a while
is recommended for more accurate conversions.
